LocalizaCerrado

Sobre o projeto:

O "LocalizaCerrado" é um projeto de desenvolvimento de software que surgiu com o objetivo de aplicar
conhecimentos adquiridos em competições de programação na resolução de problemas práticos do cotidiano.
O sistema foi desenvolvido com uma arquitetura integrada, composta por um Back-End desenvolvido por mim utilizando a linguagem C++, 
responsável pelo processamento e pela otimização das rotas, e um Front-End construído com o auxílio de ferramentas de 
Inteligência Artificial Generativa, buscando proporcionar uma interface intuitiva e uma experiência prática ao usuário.

Desenvolvimento e fundamentos técnicos:

O Back-End foi estruturado para aplicar conceitos de estruturas de dados, algoritmos e paradigmas de programação, 
aproveitando a lógica e as técnicas desenvolvidas por meio do estudo de programação competitiva.
Durante o desenvolvimento, foram trabalhados conceitos como:

- Busca Binária;
- Teoria dos Grafos;
- Algoritmo de Dijkstra;
- Programação Dinâmica;
- Bitmask;
- Manipulação de Arquivos;
- Armazenamento e gerenciamento de dados de usuários;
- Validação e verificação de dados;
- Reconstrução de caminhos ótimos;
- Representação de municípios e conexões geográficas;
- Cálculo e controle de custos operacionais;
- Análise de complexidade assintótica utilizando a notação Big O.

Arquitetura e integração:

Ao longo de aproximadamente 2 meses de desenvolvimento, o projeto evoluiu da implementação de algoritmos e estruturas de dados para a construção de uma aplicação integrada.
Nessa etapa, o foco passou a ser a conexão entre o Back-End funcional e uma interface capaz de apresentar os resultados de maneira clara e acessível.
Para o desenvolvimento do Front-End, foram utilizadas ferramentas de Inteligência Artificial Generativa,
com aplicação de técnicas de Engenharia de Prompts para orientar a construção da interface e integrar os recursos 
disponibilizados pela API desenvolvida para o projeto.

Objetivo do sistema:

O "LocalizaCerrado" tem como objetivo solucionar problemas de planejamento e otimização de rotas entre municípios do estado de Goiás e do Distrito Federal.
A aplicação utiliza algoritmos de grafos para calcular caminhos entre localidades, considerando as funcionalidades implementadas no sistema e buscando conciliar eficiência computacional, organização dos dados e praticidade de utilização.
Mais do que aplicar algoritmos isoladamente, o projeto busca demonstrar como conhecimentos de programação competitiva podem ser empregados na construção de uma aplicação de software integrada, aproximando fundamentos teóricos de problemas do mundo real.
